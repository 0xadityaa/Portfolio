# 0xadityaa.dev

Personal site and blog of Aditya Negandhi. Next.js on Vercel, content in Markdown, publishing run by GitHub Actions.

```bash
npm install --force
npm run dev
```

- Posts live in `content/blog/`. The weekly process, from topic to cross-posting, is in [docs/blog/workflow.md](docs/blog/workflow.md).
- Syndication and the secrets it needs: [docs/publishing.md](docs/publishing.md).
- Design rules and the performance budget: [docs/site.md](docs/site.md).
- Working on this repo as an agent: [AGENTS.md](AGENTS.md).

Every page is also available as Markdown for agents: add `.md` to a URL, or start at [/llms.txt](https://www.0xadityaa.dev/llms.txt).
